## 项目概述

Anthropic 官方发布的 Agent Skills 集合，覆盖**设计、文档处理、MCP 构建、技能发现/创建、Web 测试**等通用能力。这 17 个（含 1 个占位模板）是官方维护、Apache 2.0 许可的高质量技能。

---

## 技能列表（17 个）

### 1. frontend-design
- **类型**：模型调用
- **功能**：制作独特、有意图的视觉设计。覆盖排版、色彩、布局、动效、界面文案。帮助 Agent 做出不像模板化默认值的审美选择。
- **场景**：构建新 UI 或改造现有界面时

### 2. find-skills
- **类型**：用户调用
- **功能**：帮助用户从开放的 Agent Skills 生态中发现和安装技能。使用 `npx skills` CLI 搜索、检查 skills.sh 排行榜、验证质量（安装量、来源信誉、GitHub Stars），推荐安装选项。
- **场景**：想找新的 skills 来扩展能力时

### 3. skill-creator ⭐
- **类型**：用户调用
- **功能**：创建新技能、改进现有技能的完整指南。覆盖全生命周期：起草 → 写测试用例 → 并行子 Agent 评估（带技能 vs 基线）→ 评分 → 基准测试 → 描述优化（自动循环）→ 打包成 `.skill` 文件。包含完整的评估框架（grading、benchmark、A/B 对比）和打包脚本。
- **场景**：自己开发新的 Skill 时
- **注意**：这是最复杂的技能，包含子 Agent、Python 脚本、HTML 评估查看器

### 4. webapp-testing
- **类型**：模型调用
- **功能**：用 Playwright 与本地 Web 应用交互和测试。支持验证前端功能、调试 UI 行为、截图、查看浏览器日志。包含服务生命周期管理（`scripts/with_server.py`）、元素发现示例、静态 HTML 自动化示例。覆盖静态 vs 动态应用的决策树、侦察-行动模式。
- **场景**：本地 Web 应用的功能验证和调试

### 5. pdf
- **类型**：模型调用
- **功能**：PDF 文件的读取、提取/合并文本表格、拆分、旋转、加水印、填表单、OCR 扫描件。是处理 PDF 的首选技能。
- **场景**：任何 PDF 相关操作

### 6. docx
- **类型**：模型调用
- **功能**：Word 文档（.docx/.dotx）的创建、读取、编辑、模板制作，含格式化表格、页眉页码、邮件合并、修订跟踪等。生成专业 Word 报告/备忘录的首选。
- **场景**：产出 .docx 报告、信函、模板时

### 7. xlsx
- **类型**：模型调用
- **功能**：Excel/CSV 电子表格的创建、读取、编辑、清洗、公式计算、图表。处理任何表格数据首选。
- **场景**：以 .xlsx/.csv 为输入或输出的任务

### 8. mcp-builder ⭐
- **类型**：用户调用
- **功能**：构建高质量 MCP 服务器的完整指南，支持 Python（FastMCP）/Node/TypeScript，让 LLM 通过定义良好的工具访问外部服务。
- **场景**：开发 MCP 服务器时

### 9. doc-coauthoring
- **类型**：模型调用
- **功能**：文档共创的结构化工作流——需求 → 迭代打磨 → 验证对读者有效。用于写文档、提案、技术规范、决策文档。
- **场景**：撰写任何结构化文档时

### 10. canvas-design
- **类型**：模型调用
- **功能**：用设计哲学在 .png/.pdf 中创作视觉艺术（海报、静态设计）。强调原创，不复制已有艺术家作品。
- **场景**：生成海报、封面等静态视觉稿

### 11. theme-factory
- **类型**：模型调用
- **功能**：给 slides/docs/reporting/HTML 落地页等 artifacts 套主题的样式工具包，内置 10 套预设主题配色，也可动态生成新主题。
- **场景**：需要统一主题样式的展示/文档

### 12. web-artifacts-builder
- **类型**：模型调用
- **功能**：用现代前端技术（React/Tailwind/shadcn/ui）构建复杂的 claude.ai HTML artifacts，适合需要状态管理、路由的多组件 artifacts。
- **场景**：构建复杂交互式 artifact

### 13. algorithmic-art
- **类型**：模型调用
- **功能**：用 p5.js 创建算法生成艺术，支持种子随机性和交互式参数探索。
- **场景**：生成式艺术创作（偏娱乐/展示）

### 14. brand-guidelines
- **类型**：模型调用
- **功能**：将 Anthropic 官方品牌色与字体应用到 artifact，让产出带 Anthropic 风格。
- **场景**：需要 Anthropic 品牌视觉规范的产出

### 15. internal-comms
- **类型**：模型调用
- **功能**：按公司习惯格式撰写内部沟通（状态报告、领导层更新、产品简报、FAQ、事故报告等）。
- **场景**：企业内文档（个人项目基本用不上）

### 16. slack-gif-creator
- **类型**：模型调用
- **功能**：制作针对 Slack 优化的动画 GIF，含约束、校验工具、动画概念。
- **场景**：在 Slack 发 GIF（个人开发基本用不上）

### 17. template-skill（占位模板）
- **类型**：模板
- **功能**：官方提供的技能模板占位（description 为 "Replace with description"），无实际功能。
- **建议**：从 cc-switch 中删除，仅在创建新技能时参考其结构
