## 项目概述

**nuwa-skill**（女娲.skill）由独立开发者**花叔（Huashu）**创建，核心理念是——**"你想蒸馏的下一个员工，何必是同事"**。

它不仅蒸馏离职同事的思维方式，更进一步：**蒸馏乔布斯、马斯克、芒格、费曼等顶尖人物的心智模型、决策启发式和表达 DNA**。

项目名取自中国神话中造人的女娲——用公开信息为"泥土"，造出思维的"镜子"。

- ⭐ **26,000+ Stars**，3,900+ Forks
- 📄 **MIT 许可证**
- 🌐 兼容 **50+ runtime**（Claude Code、Codex、Cursor、Gemini CLI 等）

## 工作原理：4 步蒸馏流程

### 第一步：六路并行采集
6 个 Agent 同时从不同维度采集目标人物的公开信息：

| 采集维度 | 内容 |
|---------|------|
| 著作 | 书籍、文章、博客 |
| 播客/访谈 | 演讲、采访、播客 |
| 社交媒体 | 推文、公开发言 |
| 批评者视角 | 对该人物的批评和反面观点 |
| 决策记录 | 已知的决策案例和结果 |
| 人生时间线 | 关键经历和时间节点 |

### 第二步：三重验证提炼
只有同时满足三个条件才能收录：

| 验证标准 | 说明 |
|---------|------|
| 跨领域出现 | 同一模式在不同领域反复出现 |
| 有预测力 | 能解释该人物的已知决策 |
| 有排他性 | 是该人物特有的，不是"大家都这么说" |

### 第三步：构建 SKILL.md
生成包含以下结构的 Skill 文件：
- **心智模型**：核心思维框架
- **决策启发式**：做决策时的快速法则
- **表达 DNA**：语言风格和表达模式
- **反模式**：该人物明确反对的做法
- **诚实边界**：标注哪些是"确实有证据支持的"，哪些是"推断的"

### 第四步：质量验证
- 用该人物**公开回答过的问题**进行测试
- 再用**该人物从未讨论过的问题**交叉测试

## 与其他 Skills 项目的区别

| 维度 | mattpocock/skills | nuwa-skill |
|------|-------------------|------------|
| **定位** | 工程方法论 | 思维模式蒸馏 |
| **蒸馏对象** | 软件工程最佳实践 | 名人/专家的思维方式 |
| **用途** | 写出更好的代码 | 让 Agent 以特定人物风格思考 |
| **典型场景** | 开发、架构、调试 | 决策分析、创意生成、角色化思考 |
| **技能类型** | 工作流技能 | 角色/视角技能 |

两者互补：mattpocock/skills 帮你**把事情做对**，nuwa-skill 帮你**换角度看问题**。

## 使用方式

安装后，可以通过 `@人物名` 的方式激活特定思维视角：

```bash
# 安装
npx skills add alchaincyf/nuwa-skill
```

然后在对话中引用某个视角，Agent 会以该人物的思维方式来分析你的问题。

**示例场景**：
- 产品决策时，用 **Steve Jobs** 视角看取舍
- 遇到复杂工程问题，用 **Elon Musk** 第一性原理拆解
- 做投资研究，用 **Charlie Munger** 的多元思维模型
- 学新东西卡住了，用 **Richard Feynman** 的学习方法
