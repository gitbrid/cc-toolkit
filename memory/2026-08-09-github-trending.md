# GitHub 每周热点收集（2026-08-09）

## 用户需求

- 每周自动生成 GitHub 热点，周榜 + 月榜各 10-15 个（不局限于 10 个，按当周情况酌情添加）。
- 项目介绍要完整，不只是一行描述；每个项目附「你可能用到」推荐理由。
- 归档到本项目内、用 Obsidian 直接打开的库：`github-trending/`。
- 周文件夹命名格式：`2026 xx.xx-xx.xx`（周一至周日）。
- 从 2026-01-01 补录历史榜单，单独放在按周命名的文件夹里。

## 关键决策

- 三种榜单口径都做：新建仓库 Star Top、GitHub 官方 Trending、Star 增速。
- 历史只能完整回溯「新建仓库 Star Top」；Trending 历史不可回溯；Star 增速从 2026-08-10 开始积累快照。
- 脚本用 Python 标准库，零依赖，位于 `tools/github-trending/`。
- 历史补录默认不抓 README，规避匿名 API 限速；未来每周可由 Codex 润色介绍。
- 真实 Trending 页面已改版：星标增量文案是 `stars this week/month`，仓库名文本带空格，解析器需要清洗和匹配新文案。
- Star 增速榜条目必须保留完整仓库信息（链接、描述、语言等），不能只给名称和增量。

## 验证结果

- 18 个 unittest 全部通过。
- 历史补录 32 周（2026-01-01 至 2026-08-09）无失败日志。
- 当前周 2026 08.03-08.09 已生成三榜 + 月榜并真实抓取验证。
